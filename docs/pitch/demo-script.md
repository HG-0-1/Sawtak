# Seven-minute demo script

1. **Problem (0:45).** “Visitors need fast, fair voting that cannot simply be opened from home.”
2. **Solution (1:00).** Show layers: rotating physical QR, venue policy, phone OTP, database constraint.
3. **Visitor (2:00).** Open entrance display → scan → register → enter the configured demo OTP → vote across three categories.
4. **Live results (1:00).** Keep TV screen visible as the tally updates through SSE.
5. **Admin (1:00).** Open/pause voting, add a demo exhibitor, export results.
6. **Attack/scale (1:15).** Show expired token rejection, duplicate vote block, explicit residual risks, and load-test plan.

Use a clearly labelled mock OTP only in the hackathon demo. A pilot must demonstrate a real SMS delivery.
